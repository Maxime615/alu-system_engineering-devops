# Web server

Scripts that transfer files to a server and configure Nginx on Ubuntu.

| File | Description |
|------|-------------|
| 0-transfer_file | Copies a file to a server's home directory with scp |
| 1-install_nginx_web_server | Installs Nginx on port 80, serving a page with "Holberton School" |
| 2-setup_a_domain_name | The domain name pointing to web-01 |
| 3-redirection | Adds a 301 redirect for /redirect_me |
| 4-not_found_page_404 | Adds a custom 404 page containing "Ceci n'est pas une page" |
| 5-design_a_beautiful_404_page.html | A designed 404 page |
